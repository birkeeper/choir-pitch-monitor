Backend parity

Runs the same real HCQT features through the model on every available TF.js backend and compares them against the CPU backend, which is the reference. This is the test that catches a backend computing the model wrongly rather than merely slowly — a failure mode that a small synthetic fixture does not trigger, and that produced a salience map capped at 0.024 instead of 0.99 on WebGL with its default settings.

Run this in a real browser tab, not headless. Headless Chrome frequently cannot obtain a WebGPU adapter, so WebGPU goes untested there.
